# assignment2

GitHub Repository Link: https://github.com/OzieSimo/assignment2

This is assignment 2 for my Web Development Sem 1 class. The website's intention is to provide the user with a seemless exprience when it comes to restaurant choice. 
It is structured so that the user has the main navigation bar to navigate between the main home page that contains the pages introduction, a restaurant page with a list of 6 different restaurant recommendations, a register page to register an account, and a recommendation page based on user preferences as well as a direct link through either this page or the navigation bard to the Reservation page. On this page the user could have pre-filled options based on recommendations input. Here the user can make a reservation with both required and optional fields that is later validated by Javascript. If the user doesn't add required info and clicks the "reserve" button, they will be prompted with an error message stating what they need to fill out. 

Validation:
The validation process runs through man else and if statements with the variable result set by defualt to true until the program runs into a false result. Subsequently, the result then will be false and continue to move through the if statements so that it gathers additional fields that may have not been filled out and add their errormessage to the invalid notification once the user presses the button.
